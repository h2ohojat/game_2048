# 🎮 2048 — Educational Web Project

یک پیاده‌سازی آموزشی از بازی **2048** با استفاده از **HTML5، CSS3 و Vanilla JavaScript**.

این پروژه فقط برای ساخت بازی نیست؛ هدف اصلی آن تمرین یک روند مهندسی نرم‌افزار مرحله‌ای است:

- نوشتن سند مادر (Master Document)
- تعریف الزامات و محدودیت‌ها
- فازبندی توسعه
- تست هر فاز
- نسخه‌بندی (Versioning)
- انتشار Release در GitHub

## نسخه فعلی

**v1.0.0 Stable**

این نسخه حاصل تکمیل فازهای `P00` تا `P09` است.

## قابلیت‌ها

- صفحه بازی 4×4
- حرکت در چهار جهت
- ادغام صحیح کاشی‌ها
- محاسبه Score
- نگهداری Best Score
- تولید تصادفی کاشی‌های 2 و 4
- جلوگیری از ایجاد Tile در حرکت نامعتبر
- تشخیص رسیدن به 2048
- امکان ادامه بازی بعد از برد
- تشخیص Game Over
- شروع بازی جدید
- ذخیره خودکار وضعیت با LocalStorage
- بازیابی بازی بعد از Refresh
- پشتیبانی از Keyboard
- پشتیبانی از Swipe موبایل
- طراحی Responsive
- اجرای کاملاً آفلاین
- بدون کتابخانه و Framework خارجی

## اجرای پروژه

فایل زیر را دانلود یا Clone کنید:

```text
index.html
```

سپس آن را مستقیماً در مرورگر باز کنید.

هیچ سرور، نصب یا اتصال اینترنتی نیاز نیست.

## هدف آموزشی

در این مخزن تلاش می‌کنیم نشان دهیم برای گرفتن خروجی تمیز از هوش مصنوعی، بهتر است قبل از کدنویسی:

1. سند مادر نوشته شود.
2. بایدها و نبایدها مشخص شوند.
